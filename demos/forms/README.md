# 纸筏 · 形态实验室（demos/forms）

5 套**产品形态** demo（不是样式）。同一个数据（28 张便签）、五种桌面形态，用来回答一个问题：**便签墙怎么摆才用起来舒服**。

纯 HTML/CSS/JS，无构建、无依赖，双击 `index.html` 即可（推荐 Chrome / Edge）。

## 目录

```
demos/forms/
├── index.html          # 导航页
├── core.js             # 共享核心：数据、便签渲染、FLIP、拖拽、磁吸、今日聚合、外壳
├── core.css            # 共享样式：纸感卡片、纸堆、容器（撕纸线）、动效
├── 1-paper-stack/      # 方案一 · 智能纸堆墙（最完善）
├── 2-dock/             # 方案二 · 边缘收纳坞
├── 3-board/            # 方案三 · 分区展板
├── 4-timeline/         # 方案四 · 时间流
└── 5-deck-desktop/     # 方案五 · 纸堆桌面
```

## 五个形态一览

| # | 形态 | 灵魂 | 操作 |
|---|---|---|---|
| 1 | 智能纸堆墙 | 自由 + 机制自愈 | 拖=移动（磁吸）；快速松手=叠放；停留 800ms=合并（停靠点决定上下/左右分割，递归，上限 9=九宫格）；悬停纸堆扇形展开、点击摊开、拖出分离；旧便签(≥3天)自动折叠成条；今日卡左上聚合，点击直达 |
| 2 | 边缘收纳坞 | 占位最小 | 28 条收进右缘竖坞（30px/条）；点条弹出卡；拖出钉墙；拖回/📥收回；坞顶"今日"分区 |
| 3 | 分区展板 | 整齐由机制保证 | 收件箱/今日/进行中/归档四列；自动分区；拖拽换列 FLIP 重排；勾满自动飞向归档；同列可叠放/合并 |
| 4 | 时间流 | 零整理成本 | 按更新时间自动排布；<1天=大卡、<7天=中卡、更久=标题条；完成/逾期自动沉入抽屉；📌 置顶 |
| 5 | 纸堆桌面 | 桌面只剩堆 | 按颜色归堆，显示堆顶卡+厚度；悬停扇形展开（靠边自动反向防溢出）；点击摊开；拖出成新堆；拖入归堆；今日堆常驻左上 |

## 大量便签怎么看效果

每个 demo 预置 **28 张**真实感便签（服务器/契约测试/多显示器/DPI/拖拽层等真实项目内容，年龄从"刚刚"到 19 天前不等）。想再挤压密度：

- 方案一/三/四 有 `⏩ +2 天` 按钮——时间快进，看便签如何自动折叠/换区/沉底
- 方案一/三 有 `➕ 新便签`——继续堆
- 方案四 的时间流自带 28 条全形态展示（大卡/中卡/条/抽屉并存）

## 上限常量（想改就改）

九宫格上限在各自 `main.js` 顶部：

```js
const MAX_STACK = 9;   // 纸堆最多 9 张
const MAX_PANES = 9;   // 合并容器最多 9 个 pane（九宫格）
const COLLAPSE_DAYS = 3; // 方案一：几天没动自动折叠
```

超出上限会触发"轻晃拒绝"反馈。体感不合适就改数字。

## 设计要点

- **叠放** = 几何（同一位置 + 厚度边 + 角标），纯 PC 呈现层
- **合并** = 容器分割（目标卡大小不变，内部按停靠点分成左右/上下，递归，撕纸线分隔，各 pane 保留自己底色）
- **动效**：全部形态切换走 keyed-FLIP + spring 缓动；每个 demo 手感不同（纸堆=软弹、坞=快速弹跳、展板=规整重排、时间流=轻柔漂移、纸堆桌面=扇形翻牌）
- 所有 demo 与 `win/` 工程完全隔离，不参与打包
